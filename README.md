## What is Orchestrator?

Orchestrator is a platform for provisioning and managing clusters of nodes — bare-metal
machines, VMs, and especially **Raspberry Pi** fleets. It gives you:

- **Network install & provisioning** — HTTP-boot and NVMe OS deployment, no manual reflashing.
- **Fleet management** — a live view of every node, hardware fingerprint, heartbeats, and remote commands (reboot, install OS, run scripts).
- **Playbooks & workflows** — a visual editor to automate multi-step operations across your fleet, on demand or on a schedule.
- **Secrets, credentials & access** — declarative SSH access, encrypted secrets delivered to nodes, and organizational units for policy inheritance.
- **Golden images & backups** — capture and restore node images anywhere.

> Orchestrator is currently in **closed beta** at **[app.orchestrator.sh](https://app.orchestrator.sh)**.

### Before you open an issue

1. **Search first** — someone may have already reported it. Add a 👍 or a comment instead of a duplicate.
2. **One issue per report** — keep bugs and feature requests separate.
3. **Be specific** — versions, exact steps, and what you expected vs. what happened help us a lot.
